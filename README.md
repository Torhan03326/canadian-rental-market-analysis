# Canadian Rental Market Analysis

Statistical analysis of Canadian rental market data using preprocessing, correlation analysis, visualization, and exploratory data analysis in Python.

## Overview

This project explores rental property listings across Canada to identify patterns related to pricing, furnishing, property types, pet-friendly rentals, and property size characteristics.

The analysis focuses on extracting meaningful insights from real-world rental market data through statistical analysis, visualization, and exploratory data analysis (EDA). The project also emphasizes interpretation, communication of findings, and discussion of limitations rather than only presenting numerical results.

## Dataset

The dataset contains more than 25,000 Canadian rental property listings with numerical, categorical, and geospatial variables describing different property characteristics.

The analysis includes variables such as:

- Rental price
- Square footage
- Number of bedrooms
- Number of bathrooms
- Property type
- Furnishing status
- Pet-friendly status
- Province and city information

## Analysis Goals

The project investigates several key questions, including:

- Which property types provide the best value based on price per square foot
- How furnishing affects rental prices
- Relationships between property dimensions and rental cost
- Differences between pet-friendly and non-pet-friendly rentals
- Rental price distributions across provinces
- Furnishing premiums across different property types

## Techniques Used

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Distribution analysis
- Grouped statistical comparisons
- Outlier handling
- Data visualization
- Statistical interpretation and discussion

## Technologies Used

- Python
- pandas
- NumPy
- matplotlib
- Jupyter Notebook
